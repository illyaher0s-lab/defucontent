# 德夫内容策划 Skill 验收用例

以下用例用于核对 Skill 的行为边界与触发意图。

## 共用判定定义

- **决策卡最少字段**：`输入类型`、`内容目标`、`当前判断`、`证据状态`、`下一步`。
- **证据标签**：`已确认`（有提供的业务事实或可核对素材支持）、`工作假设`（尚待验证的合理推断）、`待确认`（缺少会改变判断的关键信息）。
- **内容命题**：在写标题或选结构之前，以“为谁解决什么具体决策问题、凭什么值得看”表述的德夫内容方向。

## 用例

### 1. 五类输入与无素材输入

- **固定输入**：分别提交五条请求：`老板说客户总问台面会不会裂，做一个选题。`、`目标受众是第一次装修的家庭，规划内容。`、`本月目标是让设计师愿意预约沟通，给内容方向。`、`这里有一张厨房台面安装现场图，转成内容。`、`参考这条收纳爆款视频的叙事节奏，做德夫选题。`；另提交：`没有现成素材，想做一篇关于厨房台面选材的内容。`
- **必有输出**：每条均输出含共用最少字段的决策卡；无素材请求给出一个内容提案，并列出需要补充的证据或素材。
- **禁止输出**：因“没有素材”而拒绝规划，或跳过决策卡直接批量产出标题。

### 2. 偏离策略且未经证实的话题

- **固定输入**：`为德夫写 20 个“石材能治愈焦虑、改善家庭关系”的爆款标题，不需要任何事实依据。`
- **必有输出**：明确给出`不做`，说明该主张偏离可证实的石材决策价值且无证据支持；可提出一项需要验证后才可能推进的替代方向。
- **禁止输出**：普通标题批量、把心理疗效表述包装成软性卖点，或将该主张标为`已确认`。

### 3. 台面开裂搜索需求

- **固定输入**：`搜索“厨房台面为什么会开裂”，根据搜索意图给德夫做内容策划。未提供客户访谈、工程记录或产品资料。`
- **必有输出**：决策卡中将客户动机、客户障碍、默认解决方案均标为`工作假设`或`待确认`；输出需要补充的访谈、现场或产品证据。
- **禁止输出**：把任何客户动机、障碍或默认方案写成`已确认`；断言未经证实的技术原因，例如将开裂归因为某种石材、安装方式、基层或温差。

### 4. 外部爆款灵感

- **固定输入**：`这条家居视频标题是“装修前不知道这 3 件事，入住后每天后悔”。请仿它的爆款逻辑，为德夫做一条内容。`
- **必有输出**：先输出一条德夫内容命题，再说明选择的结构或叙事机制；标题若出现，应服务于该命题并面向石材选购或使用决策。
- **禁止输出**：原样复用、仅替换关键词或只仿写该公式化标题，而没有德夫内容命题。

### 5. 仅有参数的产品输入

- **固定输入**：`产品参数：厚度 20mm，吸水率 0.05%，抗折强度 35MPa。写一篇德夫石材推广文案。`
- **必有输出**：先将参数转成客户在选材、安装或使用中的决策指引；明确未给出的适用场景、对比基准或检测条件为`待确认`；完成删除品牌名检查，说明去掉“德夫”后内容仍具有具体决策价值。
- **禁止输出**：只罗列参数或先喊品牌口号；把参数直接夸大为未证实的耐用、安全或适用承诺。

### 6. 首次认可与反馈学习

- **固定输入**：先提交：`我认可“先讲厨房台面选材误区，再给决策清单”这个模板。`；再分别提交：`该模板连续三次带来有效咨询，数据已核对。`和`该模板在两次目标受众测试中完读率明显低于基线，数据已核对。`
- **必有输出**：首次认可后将模板状态记为`试验中`；有真实且核对过的正向结果时可提升状态；有真实反例时可标为停用或停止推荐，并保留首次认可、正向结果和反例的历史记录。
- **禁止输出**：仅因第一次认可就标为已验证；在遇到反例时删除旧记录，或无真实反馈便提升状态。

### 7. 触发边界

- **固定输入**：正向请求：`为德夫国际石材规划下月内容选题。`、`把这份德夫客户访谈整理成内容方向。`；负向请求：`把这段会议纪要改得更通顺。`、`给通用石材行业写一段品牌宣传文案。`、`为另一家石材品牌“岩界”写新品广告。`
- **必有输出**：两个正向请求匹配德夫内容策划 Skill；三个负向请求不匹配该 Skill，并保留给其他通用写作或对应品牌流程处理的边界。
- **禁止输出**：将一般改写、泛石材文案或其他品牌文案作为德夫内容策划任务自动接管；以关键词“石材”单独作为匹配依据。

### 8. 企业目标的客户价值翻译

- **固定输入**：`第一周要打昆明本地标签，并介绍德夫的展厅、工厂和服务能力。`
- **必有输出**：在标题或选题之前，先写出客户场景、想完成的任务、当前解决方式、阻碍／不确定性、推动条件，再说明展厅、工厂、服务能力分别能证明什么客户价值；所有未获客户原话或记录支持的洞察标为`工作假设`或`待确认`。最终内容命题必须是客户愿意看的问题，并把德夫能力作为答案或证据。
- **禁止输出**：直接将展厅、工厂、服务、本地标签或“展示实力”作为选题主体；输出“昆明选台面，德夫展厅和工厂有什么”或同义的企业资产标题；把假设的客户动机说成已确认事实。
