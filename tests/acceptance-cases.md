# 德夫 Skill 行为验收

可复用输入与逐例预期见 `../test-prompts.json`。这些是测试定义，实际执行输出及优化备份放业务工作区 `reviews/`；禁止写入真实运营台账。

## 执行

1. 运行 `python -B tests/test_route.py`：临时工作区验证对象路由、缺依赖、写入标志、`retro/learn --record` 授权、`learn` 默认写 `02`、规则学习写 `06`、禁止 skill 数据目录和只读行为。
2. 独立 agent 按 test-prompts 执行实际任务。只读例使用业务真源；涉及写入的例在 reviews 下创建隔离工作区，复制所需标准和最小台账。记录原文输出、实际文件和前后内容验证；不能把推演标成实测。
3. 相同请求对比旧／新版，检查错误路由、漏交付、额外读写、虚构分数与输出膨胀；主文件更短本身不证明质量更好。

## 接受标准

- 普通创作交付指定篇幅／形式，不强制评分、决策卡或写台账；Full 和审稿按需加载。
- 三个阶段调用三个独立标准；任务战略项使用地图固定分。六维附证据，算术正确，未观察项不捏造或折算成完整百分制。
- 初剪／外部视频缺视频时说明边界；不能按“播放高”补出评分。缺标准给定性输出，不另造标准。
- 已授权记录才追加；现有“不记录”优先。多操作请求依次完成，复盘不自动重评发布前分。
- 所有业务记录位于解析出的 ASSET_ROOT；原标准、历史评分、版本和反例不覆盖。数据仅能关联唯一作品；重试相同事件不重复，修正值留更正历史。
- 复盘分清目标、观察期、证据与推测；先记录事实再形成一项待验证结论，单样本及混杂结果不升级稳定规则。
- 结构／模板反馈默认追加 `02`；复盘或规则性学习追加 `06`，不得把两个资产混写或用测试预期替代真实资产合同。
- 外部事实不成为德夫事实；无口播与多项目素材不被机械判失败，实际误导或无依据承诺才列红线。
- 保留原有关键防退化场景：台面开裂搜索意图不是客户事实；参数不外推承诺；外部爆款先有德夫命题再迁移机制；企业介绍先转客户价值；无素材仍给标记稿；无依据心理疗效不换词宣传；负向品牌／原始会议纪要不被自动接管。

数值评分只用于有证据的业务对象；不为 skill 优化制造绝对分提升。记录实测覆盖和未验证边界。
