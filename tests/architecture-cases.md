# 当前工作流回归测试（需 Agent 真实运行）

1. 生成20个选题，逐条执行红线与轻检，推荐10个；不可按生成顺序切片冒充筛选。
2. 用户选中其中1题后，**必须先读取 modules/writing.md**；只给这1题写5份完整图文，不写其余9题。
3. 每一版都有**封面标题**、有吸引力且兑现内容的**正文第一句**，正文**≤150字符（含标点，标题另计）**，无“时段/镜头/旁白/转场”脚本格式。
4. 五版切入差异真实，不是五套模板换词；Review 有逐版取舍，最终完整展示推荐的3版。
5. 缺德夫事实或真实素材时标待核实，不编产品参数和客户回访。
6. 飞书写入遵守用户授权和真实表结构；不因为批量任务就默认写入。
7. 正式任务评分缺外部标准时报告缺失，不编六维分数。

现有路由单元测试仍单独保留；本文件为行为验收用例，不代表已完成实际测试。
