# 当前工作流验收（预期，须实际跑 Agent 验证）

1. 20选10：逐题红线/去重/比较，禁止简单切片冒充筛选；到此暂停，等待用户选题。
2. 用户选1题后，必须读取 Writing 和 Review；只针对这一题写作，不自动处理其他题。
3. 内部生成5份完整图文，**逐份评价**消费者价值、吸引力、事实和格式；最终仅展示3份已评审的完整稿，且给简短排序理由。未经评审输出5稿视为失败。
4. 图文每篇必须有封面标题，正文第一句有观看理由，正文≤150字符（含标点），不得以视频脚本冒充。
5. 案例氛围文案可以只创造美感和向往，不强制科普或认知反转；花色应用类要表达消费者在意的可能性，不能凭空虚构性能。
6. 五个版本不能仅更换栏目名或同义词；信息事实有重大疑点的版本不能入选。
7. `scripts/validate_copy_review.py`：缺任一评审、入选不匹配、超长、编号重复时必须拒绝；5稿5评3选正常通过。
8. 正式评分缺外部真源不得编造；飞书未授权不得写入。

验证 Agent 是否实际读模块及真正进行了评审，仍需调用/执行日志；脚本不能验证美学和业务效果。
