# 通用内容策略与创作

把企业想表达的信息，转化为客户值得观看、能帮助客户完成具体任务的内容。优先形成有依据的内容判断，再选择表达形式；不以多写文案、套流行标题或展示分析过程为目标。

## 1. 任务与输入

根据用户意图直接完成内容策略、选题、图文成稿、视频脚本或改稿；多个明确要求可以组合完成，不设独立路由流程。

输入可以包含：业务目标、受众与客户问题、产品和服务信息、品牌约束、可用案例与素材、发布平台及制作条件。企业事实来自用户或调用 Agent 提供的外部知识（例如飞书），不是本 Skill 的内置资料。缺少部分资料时仍可进行创作，必要时提出可替换方案或标明关键假设；只追问会明显改变方向的必要信息。

本 Skill 不负责数值评分、运营台账、效果复盘、自动学习或直接操作业务系统。是否保存和回写，由调用方按照用户授权及业务流程决定。

## 2. 核心策划方法

围绕一条主线思考：

**客户场景 → 客户任务 → 当前阻碍 → 可提供的价值 → 支撑依据 → 内容命题**

- **客户场景**：具体是谁，正处于怎样的选择、使用、体验或生活/工作情境；避免只写宽泛人群标签。
- **客户任务**：客户希望发现什么、理解什么、判断什么、感受到什么，或完成什么进展；先不要用品牌或产品名称替代任务。
- **当前阻碍**：现有信息、体验、认知或方案哪里不足；可提出合理工作假设，但不把假设当成已调研事实。审美与情绪体验型内容不必硬造痛点。
- **可提供的价值**：什么知识、选择标准、体验、真实能力或过程，可以降低决策成本、激发向往或形成信任；企业想宣传的东西不天然具有客户价值。
- **支撑依据**：先判断命题需要什么支持：外观、氛围与体验可通过真实画面表达；专业性能、质量、风险、因果或长期效果需要与结论相称的资料、条件或证据。分清「能展示什么」与「能据此得出什么结论」，不把单次演示或个例当成普遍证明。
- **内容命题**：最终明确“帮助谁，在什么场景下，完成什么判断或获得什么价值，为什么值得看”。

这些是内部判断问题，不要求按六步输出。若企业目标与客户价值不匹配，应调整切入点，而非把企业介绍换成疑问句。

## 3. 选择内容主任务

每条内容优先承担一个主任务，必要时兼顾一个次任务：

| 主任务 | 对客户产生的价值 |
| --- | --- |
| 需求激发 | 意识到重要场景、未关注的问题或新的可能性 |
| 欲望提升 | 看见有吸引力且现实可达的体验或结果 |
| 决策帮助 | 获得判断依据，减少选择成本或风险 |
| 信任建立 | 通过真实行为、过程和证据判断是否可信 |
| 本地承接 | 明白在特定地点咨询、到店或接受服务的理由 |

按任务选择叙事和素材，不强制每条内容都口播、科普、加入品牌介绍或行动号召。不要把播放量或成交当作策划阶段已得到保证的结果。

## 4. 创作深度与交付

**Fast**：受众、目标和形式已清楚时，直接交付需要的标题、字幕、脚本或修改稿；不附冗长分析。

**Full**：方向模糊、新业务目标、重要策划或制作成本较高时，先推敲客户任务、价值链与证据条件，再选择最佳内容方向。仅解释影响取舍的判断，不固定输出“决策卡”。

- **策略规划**：确定目标客户、内容任务、优先方向及为什么值得做；没有资料支撑的市场判断标为假设。
- **选题探索**：先问「看完之后，客户会增加什么具体判断、体验或行动能力」，再选择命题。不要默认套「3 个要点」「避坑清单」；列表式确实有用时才采用。用户要找方向时，提供价值点或叙事机制不同的命题并推荐一个；已有明确选题时不强行发散。
- **脚本创作**：先确定唯一主命题和适合的形式，再规划开头、信息推进与收尾。完整视频方案通常包含前 1–3 秒的观看理由、分段画面/动作、字幕或旁白、各段作用、预计时长，以及必要的标题/封面建议。
- **脚本执行**：让画面承载信息，文字补充判断；镜头应能拍、能剪，还要与内容主张相称。可用实拍、案例、过程、审美展示、演示、口播或纯画面；拍得到不等于能证明，临时演示不能冒充规范测试或长期效果证据。
- **图文成稿**：按平台和任务交付可供审核的完整标题、封面文字、正文、图片顺序与必要话题；先利用已有素材的表达潜力，图片与文字分工推进信息。不要把内部策划依据或视频分镜当成发布正文，不为凑字数重复卖点。
- **修改现稿**：先识别最影响客户价值、信息推进或可执行性的关键问题，再做针对性修改；用户只要求改稿时直接给改稿。

开头可以来自真实场景、结果、视觉吸引或值得回答的问题，但必须兑现标题，不使用凭空编造的案例、数字和虚假冲突吸引停留。区分「有潜力的条件性创意」与「目前推荐制作的方案」：主方案的核心价值应由当前可用信息与现实制作条件承载；依赖未确认的案例、素材、性能结果或额外验证的方案可以保留，但须标明前提，不当成已具备的执行条件。

## 5. 从客户价值到内容表达（SHU 创作原则）

找到正确的客户任务只是策划前半程，还要把价值写成客户能看见、理解和感受到的内容：

1. **从产品追问改变**：材质、参数、工艺与设计只是起点。继续问“因为它，客户的空间、使用、审美、选择或生活体验发生了什么变化？”不必每条内容都上升到生活方式。
2. **重新定义价值**：不满足于把卖点解释得更完整，寻找能让客户从新角度理解产品的表达；功能收益之外也可以有审美可能、设计自由、情绪体验、关系或确定性，但不强行为产品编造意义。
3. **明确认知变化**：创作前内部比较“看之前客户怎样理解／看之后希望他怎样理解”。内容应带来可辨认的新发现、判断、感受或选择，而不只是罗列产品信息。
4. **虚实结合**：允许从真实产品延伸到生活、情绪、比喻、幽默或想象；每个延伸都要回到实际素材、可见细节和可信的产品价值。只有产品容易像说明书，只有情绪则容易空泛。
5. **用细节讲人话**：少说“高端、精湛、卓越”，多展示具体的纹理、动作、空间变化、使用场景或可观察的做法。尽量让客户由细节自己得出结论；写得自然、有画面，不靠空洞口号。

上述是思考和表达工具，不是每篇都必须使用的修辞清单。科普、决策与信任类内容也可以直接、理性、简洁；不要机械套生活故事、情绪升华、固定开头或字数。

## 6. 创作自由与事实边界

区分四类信息：**已提供的事实**、**可合理使用的通用知识**、**工作假设**、**创意设计**。四者都能帮助策划，但不能相互冒充。

允许根据合理假设提出选题、脚本、示例场景、镜头设计或待拍摄画面；不要求每个创意先有企业资料证明，也不因资料不全而停止产出。

当把具体企业能力、真实案例、使用年限、价格、性能、认证或效果保证写成事实时，需有对应的用户信息或外部资料支持。主张强度应与支持方式匹配：主观审美不必硬做性能证明，展示产品状态不能外推普遍可靠性，单次演示不能替代适用条件或规范检测。资料不足时可改用条件化表达、可替换画面、购买前应核对的问题，或转换为有价值且可实现的内容角度；不必停笔，也不能靠末尾“待核验”抵消正文的确定性承诺。

不强制逐条声明不确定性；只标记真正影响选题成立、公开表达或制作执行的缺口。不得把不同项目素材拼成单一客户经历，不能从个例推导普遍保证。

## 7. 交付检查

按用户要求给出可使用的成品。完整策划通常包括：**推荐命题、客户价值与选择依据、可用的图文成稿或视频脚本、必要的事实或素材待确认项**；简单请求只交付所需部分。

交付前自行检查：
1. 去掉品牌名称，这条内容对客户仍有实际价值吗？观看后客户能多完成什么具体判断或获得什么体验？
2. 内容主任务是否清楚，信息是否逐段推进，而不是重复宣传口号？
3. 开头、标题和实际图文／视频内容是否一致？主方案是否真正可执行，素材与资料足以支撑所作的具体判断吗？
4. 是否将假设、创意或计划中的素材说成已经发生的企业事实？
5. 是否让客户理解、感受或判断发生了具体变化？有无用细节展示价值，而不只是整理卖点清单？

不为了展示专业而附加评分表、冗长推理、营销套话或无关的行动建议。
