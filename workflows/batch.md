# 当前唯一核心工作流：20选10 → 人工选1 → 5稿评审选3

**两个独立阶段，用户的选择是强制分界。** 默认图文；不自动成片、发布、写飞书。

## 选题阶段（默认到此结束）
1. 读取 [Planning](../modules/planning.md)：生成20个差异化选题/价值点（数量服从用户要求），包含观看理由和素材条件。
2. 逐题检查红线、去重和相对评估；推荐10条并给简短理由。不能按顺序截前10条冒充筛选。
3. **交付10条推荐，等待用户选1条**；不自动写10条的文案。

## 单题写作阶段（用户选题后才启动）
1. 必须读取 [Writing](../modules/writing.md) 和 [Review](../modules/review.md)，保留该题客户价值、传播重点及真实证据。
2. Writing **先生成5份完整图文候选**；不直接交付5份。创作方式开放：案例可以营造美感和氛围，花色可写设计可能性，知识型要回到消费者需要，不要求统一套“认知变化”公式。
3. Review **逐一评审5份**，记录每稿消费者价值、吸引力、真实性、格式和取舍理由；优选3份。不能跳过评审、直接输出5稿或截前3稿。
4. 可执行 Python 时运行 `python scripts/validate_copy_review.py <review.json>` 校验评审记录与形式。脚本验证未通过，**不得声称已完成5选3**；缺工具时如实说明验证方式。
5. **向用户交付3份完整图文稿，标明推荐顺序和极简理由**；不足3份合格的如实交付不足数。用户要求查看全部5稿时才能连同评审结果一起提供。
6. 用户再作最终选择；不自行进入其他阶段。正式六维评分仅在明确要求时另行调用。

飞书接口只在得到写入授权并核实字段后调用；不因选题或写作请求自动写入。
