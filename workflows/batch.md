# 批量工作流
适用于批量选题、批量脚本或素材驱动的内容供给。按用户要的截止阶段停止，**不自动发布**。

1. Planning：输入目标和素材 → 多样化候选；去重、排序、标缺口。
2. Review 轻检：优先保留低风险、可执行的命题；选题不足不凑数。
3. Writing：对入选条目批量出稿，每条保留候选标识、核心主张及所需素材。
4. Review 轻检：通过/自动修一轮/待补证/放弃，最多自动修一轮；只呈现需要人工决定的问题。
5. 交付清单：已通过数量、待补证、需补拍素材、下一步。仅用户要求正式评分时另走三阶段评分。

默认不写数据、不创建外部表格；只有明确授权且 Agent 可用的工作台适配器，才回填。批量模式没有自动视频生成或自动发布能力。
